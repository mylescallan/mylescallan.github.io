In this chapter, three methods of creating objects (with properties and methods) are covered: Object Literal Syntax, New Object Syntax, and Function Syntax. Using the Function Syntax makes the most sense as it allows you to create a 'shell' object and then fill in the values later. 
    
// 3. Create a hotel object using "function" syntax
    function Hotel(name, roomRate, discount) {
// name, roomRate, and discount are properties of the "Hotel" object:
    this.name = name;
    this.roomRate = roomRate; // Amount in dollars
    this.discount = discount;  // Percentage discount
// offerPrice is a method, created by defining an object function:
    this.offerPrice = function() {
    var offerRate = this.roomRate * ((100 - this.discount) / 100);
    return offerRate;
    };
  }
  var hotel = new Hotel('Blarty', 240, 50);
